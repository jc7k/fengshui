# Start Here 👋

Welcome to your Feng Shui Home Analyzer. This Obsidian vault is your **notebook and
textbook combined** — the place where the feng shui, the code, and your own notes live
side by side.

This is a self-paced project. You already know some feng shui; here you'll learn to
*compute* it, and pick up real programming along the way. **Jeff is available to help you
at any time:** no deadlines, no scheduled check-ins.

## Read this first
Before anything else, read [[../01-Feng-Shui-Fundamentals/A-Note-on-Honesty|A Note on Honesty]].
It sets the frame for the whole project: we treat feng shui as a **living tradition worth
taking seriously**, *and* we're candid that it's an art, not a science — and that its schools
openly disagree. Holding both at once is the mature way to study it.

## How this vault is organized
- **[[../01-Feng-Shui-Fundamentals/Chi-Yin-Yang|01-Feng-Shui-Fundamentals]]** — six short
  primers on the core ideas. Read each *before* the code that uses it.
- **02 → 09** — one folder per module (Week 1 through the bonus). Each has:
  - `Module-Guide` — what you're doing this week and why
  - `Code-Checkpoint` — what "working code" looks like at this stage
  - `Lab-Notes` — prompts to fill in as you work
  - `Reflection` — what surprised you, what to ask a practitioner
- **[[../99-Resources/Glossary|99-Resources]]** — glossary, sample-home notes, links & citations.

## The one idea that ties it together: the Whole Game
You will **not** spend weeks on theory before building. In **Week 1 you build a working
analyzer** that reads a home end to end. It's crude on purpose. Every week after, you add one
real feng shui school as a new *lens* on that same tool:

| Week | What you add | The analyzer goes from… |
|---|---|---|
| 1 | The whole game runs | nothing → a crude working map |
| 2 | The Five Elements engine | naive flags → tips that explain *why* |
| 3 | Eight Mansions (your Kua) | impersonal → tuned to the people |
| 4 | Flying Stars (the natal chart) | static → aware of *when* it was built |
| 5 | Form School (the shape of space) | interior-only → site-aware |
| 6 | BTB vs compass, side by side | one map → two maps that disagree |
| 7–8 | The capstone report | lenses → an honest decision aid |

## How to actually do the work
1. Open the week's `Module-Guide` here in Obsidian.
2. Open that week's notebook (in `notebooks/`) in Google Colab — see [[../../GETTING_STARTED|GETTING_STARTED]].
3. Code along. **You write the key cells yourself** — the notebook tells you which.
4. Come back here and fill in `Lab-Notes` and `Reflection`.

## A standing rule
**You can ask Jeff for help at any time.** No scheduled check-ins, no deadlines. If you're
stuck for more than a few minutes, that's exactly when to reach out. Getting unstuck fast is
a skill, not cheating.
